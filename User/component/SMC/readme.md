# 【2026 复旦大学·星云 EGA】云台 yaw 角度滑模外环

## C 语言使用说明

实现文件为 `slidingmodec.c`，类型为 `SMC_t`，参数和运行观测沿用扁平结构。
本工程在原作者版本上改为**线性滑模面并直接输出电流**，参数含义与原作者版本不同，不能直接套用原示例数值。

控制器按下面的控制律生成候选电流：

```text
e     = angle - target
e_dot = ang_vel - target_dot
s     = e_dot + C * e
u     = J * [target_ddot - C * e_dot - K * s - epsilon * sat(s / surface_eps)]
```

其中 `u` 单位为 A，正方向与角度增大方向一致，最终仍由云台模块按 `max_current_a`、机械边界和输出闸门限幅。

参数：

| 字段 | 单位 | 说明 |
| --- | --- | --- |
| `C` | 1/s | 滑模面系数，越大收敛越快，噪声敏感性越高 |
| `K` | 1/s | 线性趋近系数，越大趋近越快，过大易抖 |
| `epsilon_deg_s2` | deg/s² | 切换项幅值，乘 J 后为切换电流，过大会产生电流毛刺 |
| `J` | A/(deg/s²) | 等效惯量与电流换算增益，唯一需要标定的尺度 |
| `surface_eps_deg_s` | deg/s | 饱和边界宽度，加宽可减小静止抖动，过宽会变软 |

参考轨迹由 `SMC_AdvanceReference` 按实际周期推进，输出 `target`、`target_dot`、`target_ddot`，
再调用 `SMC_Tick` 生成 `u`。起控和模式切换时要先把 `target` 捕获为当前姿态并清零参考导数，避免追赶旧目标。

`J` 的上板辨识：固定一个小电流（例如 0.2 A），记录角加速度 α，按 `J = u / α` 计算，正反方向各测一次取平均。

调参顺序建议先确认方向与 J，再调 `surface_eps` 和 `epsilon` 压制抖动，最后调 `C`、`K` 提高响应。
控制频率变化或更换电机、改变限流后需要重新确认参数。

初始化和每周期在线调参边界先调用 `SMC_IsConfigValid`，计算函数信任已校验的参数和非空实例。
`SMC_Tick` 在写入 `u` 前检查计算链出口是否有限，非有限时返回假，由模块进入故障并输出零电流。

数学函数使用 `<math.h>` 中的 `fminf`、`fmaxf`，GCC 链接时需要数学库 `m`。
CMake 和 Keil 工程均已加入 `.c` 文件；pitch 和 SPEED 模式继续使用 PID。
