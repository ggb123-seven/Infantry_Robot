# Infantry_Robot

基于 DJI RoboMaster C 型开发板的步兵机器人控制工程，主控为 STM32F407IGH6，使用 STM32 HAL、FreeRTOS 和
CMSIS-RTOS2。工程已完成底盘、云台、发射机构和底盘功率限制的主体功能，BMI088 + Madgwick 姿态解算已接入
云台闭环，业务代码按任务、模块、组件、设备、BSP 五层组织。

## 当前功能

### 遥控与总线

- DR16 遥控接收与解析：USART3 + DMA，100 kbps、9 位偶校验，失联时各模块回到待机输出
- CAN1、CAN2 双总线设备管理（1 Mbps）：反馈采集、在线检测、电流命令统一组帧发送
- CAN 设备映射：CAN1 挂四路底盘 M3508（电调 ID1~4）和 yaw GM6020（ID5）；CAN2 挂 pitch GM6020（ID6）、
  两路摩擦轮 M3508（ID5、ID6）和拨弹 M2006（ID7）

### 底盘

- X 型全向轮运动学混控（`User/component/mixer.c`），四轮转速解算与输出轴电流统一限幅
- 四轮速度闭环 + 在线可调前馈，反馈二阶低通滤波，离线轮隔离与恢复后自动重新预置
- 指令层斜坡（默认 200 rpm/s）、轮速上限 300 rpm、转子电流上限 10 A
- 跟随云台角度 PID：以云台相对车头的最短机械角为反馈，误差按 2π 环绕
- 小陀螺自旋：平移坐标随云台旋转，底盘运行状态经邮箱发布给云台用于悬空带转判断
- 待机、独立、跟随云台、小陀螺四种模式的状态机，待机与离线时由 `Chassis_DumpOutput` 统一零输出

### 功率限制

- `User/module/power.c`：固定功率上限 + 电机模型功率环 + 四轮功率再分配，超限时按置信度反解各轮电流
- 当前按可配置的 90 W 上限运行（无裁判系统），配置副本支持调试器在线修改，每周期只在 Control 入口校验一次
- 系数为参考工程初值，尚未按本车标定；主机单测与构建验证已完成，未上台架实测

### 云台

- GM6020 两轴，500 Hz 角度-速度串级 PID，速度环输出限幅 1.0 A
- 惯性反馈来自 INS 同帧快照（大地系欧拉角速度），编码器角度用于机械观测与限位
- yaw 二次摩擦前馈（`i = a0 + a1·v + a2·v²`），按闭环目标角速度门控，静止段用零速过渡区连接
- pitch 重力前馈（`i = A·cos(θ - θ0) + i0`），θ 取 IMU 大地系俯仰角
- 机械行程约束、反馈超时断开连续角、零点/方向切换、配置变更、周期异常等故障锁存
- yaw 悬空带转保护：底盘四轮全部离线时，编码器与惯性转速持续不一致则撤驱，命令回到 RELAX 后解除
- RELAX、SPEED、ANGLE 三种模式与单轴状态机，所有输出经 `Gimbal_DumpOutput` 单一闸门

### 姿态解算

- BMI088（SPI1，10.5 Mbit/s）+ Madgwick AHRS，1 kHz 更新，输出四元数、欧拉角、累计 yaw、
  机体系/导航系运动加速度和安装误差修正矩阵
- 加热器由 TIM10 PWM 驱动，PID 温控按 500 Hz 分频执行
- 姿态快照经邮箱发布给云台，采样时刻随帧传递，接收端按源时刻校验帧龄

### 发射机构

- 双摩擦轮：两路 M3508 独立速度环 + 一秒启停斜坡，命令邮箱超时保持并带落空/打断诊断计数
- 拨弹：M2006 角度-速度串级闭环，一圈 8 齿、每秒最多 20 齿，支持单发、连发和五连发；
  射击模式由在线变量 `feeder_remote_fire_mode` 选择（默认单发），DR16 右拨杆只决定安全、备弹和开火，
  定量进给与释放重触发由拨弹模块独占

### 系统与调试

- 业务任务 7 个：CAN、底盘、云台、双摩擦轮、拨弹、DR16、INS；控制频率 500 Hz，INS 1 kHz，
  统一使用 `osDelayUntil()` 保持周期
- `Task_Init` 集中创建业务任务和消息队列，全部成功后才解锁调度器，失败时回收已创建对象
- 故障检测模块输出系统级、逐电机和 DR16 链路位域快照
- 在线调参：`User/module/config.c` 的只读默认配置在初始化时复制到实例副本，可用 EmberProbe 运行中修改，
  每个控制周期在 Control 入口做一次快照校验后再使用
- 500 Hz 片上调试记录（`MOTOR_GIMBAL_ENABLE_DEBUG_LOG`，64 kB 静态缓冲，默认编译关闭），
  用于角度环辨识，不参与控制计算
- USB CDC 虚拟串口已由 CubeMX 初始化，尚未接入调试协议

## 工程结构

业务代码按以下方向依赖，禁止下层反向依赖上层：

```text
User/task -> User/module -> User/component 或 User/device -> User/bsp -> STM32 HAL
```

主要目录用途：

| 目录 | 用途 |
| --- | --- |
| `Inc`、`Src` | STM32CubeMX 生成的启动代码、外设初始化和中断入口 |
| `User/bsp` | CAN、UART、SPI、GPIO、时间和内存等板级接口 |
| `User/device` | DR16、M3508/M2006/GM6020 电机、BMI088 和 CAN 设备协议 |
| `User/component` | PID、滤波、混控、Madgwick 姿态解算、限幅和数学工具 |
| `User/module` | 底盘、功率限制、云台、INS、摩擦轮、拨弹、命令解析、故障检测和整机配置 |
| `User/task` | FreeRTOS 周期调度、消息路由和模块编排 |
| `applications` | 指示灯任务 |
| `docs` | 工作流记录、上板验证记录和分析报告 |
| `tools/matlab` | yaw 系统辨识与整定脚本 |

## 构建工程

构建环境需要：

- CMake 3.22 或更高版本
- Ninja
- GNU Arm Embedded Toolchain（`arm-none-eabi-gcc`）

工具链可通过系统 `PATH`、`ARM_GNU_TOOLCHAIN_ROOT` 或 `CUBE_BUNDLE_PATH` 提供。配置并构建 Debug
版本：

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

构建产物位于 `build/Debug`。Release 构建使用：

```powershell
cmake --preset Release
cmake --build --preset Release
```

同时保留 Keil MDK 工程 `MDK-ARM/Infantry_Robot.uvprojx`，新增源文件时需与 CMake 源文件列表同步登记。

## CubeMX 配置

硬件配置保存在 `Infantry_Robot.ioc`。重新生成代码前应先确认本地 STM32CubeMX 版本及改动范围，生成后检查
外设配置、CMake 源文件列表、Keil 工程和用户代码是否保持完整。

## 调试与验证

- 变量读写、在线调参和采样通过 EmberProbe 完成；探针链路实测单变量约 73 Hz、多变量 50~67 Hz，
  控制周期的精确记录使用片上 500 Hz 日志
- 辨识与整定脚本在 `tools/matlab/`，按闭环辨识流程先拟合闭环传函再反解对象，并校验直流增益与带宽
- 验证记录按日期归档在 `docs/validation/`，方案与对比分析在 `docs/analysis/`，会话工作流记录在
  `docs/workflows/`

## 开发状态

已上板验证的主要功能：

- 底盘四轮速度环、运动学混控、跟随云台和小陀螺模式
- 云台两轴串级闭环、INS 惯性反馈、摩擦与重力前馈、机械限位和故障保护
- 摩擦轮启停斜坡、拨弹角度-速度闭环、单发/连发/五连发逻辑
- BMI088 采样、Madgwick 姿态解算与加热温控

仍在进行或尚未验证的内容：

- 功率限制模块只有主机单测和构建证据，`power_config` 系数未按本车标定，未上台架做实物功率测量；
  2027 裁判系统驱动、缓冲能量环和在线参数辨识尚未实现
- yaw 存在 13.5 Hz 结构共振，小陀螺工况下角度峰峰值约 0.75°~0.80°，未达到 0.2° 目标；
  `kp=1.2` 时存在 7.82 Hz 极限环风险
- 云台没有积分项和扰动观测器，实测静差约 0.2°、阶跃超调约 11%，大机动工况超调更高；
  阻尼比约 0.66，继续加 D 会与摩擦前馈耦合，调参受限
- 拨弹定量进给在实弹连发下的稳定性、摩擦轮弹速标定仍需验证
- 任务运行时栈高水位、长时间连续运行等系统级验证尚未系统开展

## 安全提示

该工程用于 RoboMaster 机器人开发和调试，仍包含未完成和未标定模块。上电测试前应架空底盘、限制输出，
