# yaw 角速度滤波重定与小陀螺抖动复测（2026-11-18）

> 前置：`gimbal_spin_jitter_handoff_20261118.md`、`yaw_id_excitation_plan_20261118.md`

## 1 结论

- yaw 惯性角速度反馈去掉 13.5 Hz/8 Hz 陷波，低通 20 Hz 提到 40 Hz；pitch 仍为原参数
- 同工况（`CMD_CHASSIS_SPIN_WZ = -0.50`，电机相对转速 -1.79～-1.81 rad/s，角度环 d=0.05）下，
  yaw 角度峰峰 1.007° → 0.49～0.61°，RMS 0.244° → 0.11～0.13°，两窗重复
- 角度环 d=0.15 两窗 RMS 0.087°/0.108°，与 d=0.05 的窗间离散同量级，用户实操感觉 0.05 更好，维持 0.05，`config.c` 未改
- 剩余抖动是每转 10 次与 20 次的周期力矩（约 2.8 Hz、5.7 Hz，各约 0.07～0.1°），滤波和 d 压不动；
  用户决定后续直接换 LADRC，不做按机械角的纹波补偿

## 2 机理

- 激励辨识（底盘静止 S1 两窗，各频点信噪比 7～159）：电流到陀螺对象约 27～31 rad/s²/A 的积分器，
  与 Kt/J=32.79 吻合；模型预测的激励到电流闭环响应与实测在 1.5～13 Hz 内差约 5%、4°
- 模型复现历史现象：速度环 Kp=1.2 增益裕度 +0.3 dB @7.5 Hz（实测 7.82 Hz 自激）；
  增益裕度随 d 增大而减小，与 d=0.05/0.2/0.5 的实测好坏顺序一致
- 原滤波在 6.35 Hz 滞后 46°，增益裕度只有 1.1～1.6 dB，扰动放大峰值 6.7 倍 @6.35 Hz
- 小陀螺扰动频率随电机相对转速同比移动：wz=-0.30 时峰值 1.68/3.36 Hz，wz=-0.50 时 2.86/5.73 Hz，
  均为每转 10/20 次；11-16 只转云台的摩擦标定数据里同样有每转 10/20 次电流纹波（0.028/0.017 A）
- 加速度计约 24 Hz 峰同样随转速移动（每转约 80 次），不是固定结构共振，13.5 Hz 陷波对不准
- 小陀螺工况激励数据（A2 三窗）不可用：目标速度均值 -0.175 rad/s 贴近前馈拐点 0.2，仅 55% 样本在线性区
