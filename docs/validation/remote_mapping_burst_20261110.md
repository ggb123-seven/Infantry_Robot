# 2026-11-10 遥控映射同步与五连发

## 行为

- 右拨杆上位进入安全档：拨弹撤驱，摩擦轮持续使能并以 0 rpm 闭环制动
- 右拨杆中位进入备弹档：拨弹保持当前位置，摩擦轮以 8000 rpm 运行
- 右拨杆下位开火：默认五连发，拨弹每齿均须到位并满足原有速度、角度稳定时间和发射间隔；五齿完成后持续下位不重复
- 单发、五连发和持续连发接口均保留，`feeder_remote_fire_mode` 取值分别为 1、2、0，复位默认 2
- 固定发数模式回中立即取消尚未完成的目标，重新下位前须再次中位备弹；失联、输出发布失败或恢复后仍下位均不续打
- 左拨杆上位以四轮速度环零目标制动，中位云台坐标跟随，下位在云台坐标平移并顺时针自旋
- 右摇杆仅控制云台；正常遥控通信使能云台两轴角度环和速度环，原遥控环路开关继续开放且手动调试来源保持独立
- 不修改 config.c 参数，不新增结构体字段；复用现有结构体并增加底盘自旋模式枚举和拨弹模块私有标量
