## 解释与边界

Roll/Pitch 在本次静置工况下的短时标准差约 0.025°；没有外部角度基准，均值不能作为绝对精度或零点误差
温度结果反映预热后约一分钟内的稳态波动，没有测量冷启动升温超调或更长时间的温度漂移
Yaw 斜率反映本次短时测量，不能直接外推为全天漂移；六轴重力反馈不能提供绝对航向参考

主机读取多个字段不是一致性快照，而且主机采样频率远低于 INS 的 1000 Hz 更新率
`valid=0` 共采到 132 次，源码在每次更新前清除此标志，成功更新后重新置位
这些点不单独计为故障；状态码始终为零，更新计数持续增长
各字段的边际统计可供静止基线比较，但不得把跨字段瞬时组合用于高精度动态重建
加速度模长也是跨字段派生量，三轴角速度低速采样均值不能代替完整带宽的零偏标定

在线修改 `INS.ahrs_beta=0.02` 的预检查返回 `WRITE_NOT_ALLOWED`，错误消息为：
`Writing C++ runtime container or dynamic member is not supported: INS.ahrs_beta`
写入未执行，读回仍为 `0.033`；没有改用原始地址或其他写入途径绕过限制
首次长采样随后返回 `Sampling session stopped`，不保留为有效基线；恢复采样后才取得上面的完整记录

本次尚未完成不同 beta 的实物对照、倾斜启动收敛、已知角度准确度、振动与平移加速度测试
当前证据支持保留 `0.033` 作为继续验证的基线，不能据此宣称它是最佳参数

## 调参建议

| 参数或配置 | 本次建议 | 仍需的测量 |
|---|---|---|
| `INS.ahrs_beta=0.033` | 暂时保留，已取得静止基线 | 在相同供电、温度和动作下比较多个 beta 的抖动、跟随与恢复 |
| BMI088 陀螺零偏、加速度比例 | 使用现有校准流程，不按本次低速均值直接覆盖 | 稳定供电、目标温度下重复静止校准及多次启动一致性 |
| 安装角、轴向和正负号 | 无角度基准，不据桌面均值设零 | 固定安装方向、已知正反角度及组合姿态 |
| `MotionAccelLPF=0.0085 s` | 尚无证据需要修改 | 平移和振动工况下的一致性、高速数据 |
| 温控目标 40℃、现有 PID | 暂时保留；不能用断电降温段调 PID | 稳定供电下冷启动、升温超调与长时间稳态 |
| Yaw 漂移补偿 | beta 不能提供绝对航向约束 | 多温度、多次启动零偏测试，必要时外部航向观测 |

安装参数仍沿用旧字段命名：`correction_pitch_deg` 实际修正 X 轴，`correction_roll_deg` 实际修正 Y 轴，
不能直接按新输出字段 Roll/Pitch 的名字判断其轴向。
