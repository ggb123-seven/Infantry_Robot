## 0. 结论速览

1. 采用 `A·cos(θ - θ₀) + i₀`，θ 取 IMU 大地系俯仰角，不辨识负载质量
2. 质量、重力加速度、质心力臂、力矩常数、减速比全部合并为唯一幅值 A，单独辨识质量没有可辨识性收益
3. 标定用线性最小二乘解 `(a, b, c)` 再换算 `A/θ₀/i₀`，不做非线性迭代
4. 字段全零即关闭，`config.c` 未赋值，改动前后行为逐位一致
5. 标定流程见第 5 节，参数只在 RAM 副本中生效

## 1. 模型与参数

```text
τ(θ) = m·g·l·cos(θ - θ₀)        物理重力力矩
i(θ) = A·cos(θ - θ₀) + i₀       A = m·g·l / Kt
```

- `A` 吸收 m、g、l、Kt、减速比、驱动器电流换算，单位 A，范围 [0, max_current_a]
- `θ₀` 是重力力矩最大处的大地系俯仰角，单位度，范围 [-180, 180]
- `i₀` 是与角度无关的常值项，吸收线束、装配与静摩擦偏置，单位 A
- 约束：`A + |i₀| ≤ pitch.max_current_a`，保证未限幅的合成值本身有界

## 2. 为什么用线性最小二乘而不是非线性拟合

pitch 机械行程只有 [-20°, 20°]，在这么短的区间里 cos 几乎是直线，参数不可辨识、预测可辨识：

| 基函数 | ±20° 条件数 |
|---|---|
| `(cos θ, sin θ, 1)` | 9833 |
| `(1, θ, θ²)` | 6.9 |
| `(1, θ)` | 1.0 |

蒙特卡洛（真实 A = 0.5 A，电流噪声 σ = 0.01 A，2° 步长 21 点）：

- 拟合曲线在区间内的预测最大误差 3.8%～4.2%（相对 A），够用
- 但 A 的标准差 0.055～0.115 A，θ₀ 的标准差 1.3°～11°，取决于真实 θ₀

因此：标定时对 `i = a·cosθ + b·sinθ + c` 做线性最小二乘（正规方程一次解完），
再换算 `A = hypot(a, b)`、`θ₀ = atan2(b, a)`、`i₀ = c`。数学上完全等价，不要对 `(A, θ₀)` 做迭代拟合。

附：用二次式 `(1, θ, θ²)` 拟合 cos 在 ±20° 内最大偏差只有 0.24%，区间内形状选型不影响精度；
仍选 cos 形式，是因为超出标定区间时 cos 外推物理正确，二次式会发散。

## 3. 代码落点

字段（`gimbal.h`）：

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `pitch_gravity_enabled` | bool | - | 总开关，零初始化即关闭 |
| `pitch_gravity_current_a` | float | A | 幅值 A |
| `pitch_gravity_angle_deg` | float | ° | 相位 θ₀ |
| `pitch_gravity_bias_a` | float | A | 常值项 i₀ |

实现（`gimbal.c`）：

- `Gimbal_IsPitchGravityConfigValid`：配置入口集中校验，挂在 `Gimbal_IsConfigValid` 上，每周期只做一次
- `Gimbal_CalcPitchGravity`：`A·cos(θ·deg2rad - θ₀·deg2rad) + i₀`
- 叠加点：`Gimbal_RunAxis` 速度环输出之后、`AbsClip(current_a, max_current_a)` 之前，与 yaw 摩擦补偿并列
- 前馈角用 `axis->angle_deg`（IMU 大地系俯仰角），不用 `mechanical_angle_deg`；
  编码器机械角含底座姿态偏差，底盘上坡或被顶起时会系统性偏
- 前馈是加在速度环输出上的开环偏置，速度环积分会自动退让补差，不是双补
- 输出仍由 `Gimbal_DumpOutput` 唯一闸门按轴状态放行，不新增兜底

## 4. 当前闭环的重力承担方式

- pitch 角度环 `i = 2.5` 但 `i_limit = 0`：`pid.c` 的积分接纳条件是 `|新积分量| <= i_limit`，
  零限幅使积分永远停在 0，角度环实际等价纯 P（Kp_eff = k·p = 10 (rad/s)/rad）
- 重力实际由速度环积分承担，上限 `i_limit × i = 1.4 × 0.5 = 0.7 A`，而总输出限幅 1.0 A
- 历史数据 `docs/analysis/pitch_hold_torque_20261111.md` 中一阶重力模型不可辨识
  （cond 161.7、R² 0.566、A_g = 3.83 ± 1.96 A），原因是当时 `i_limit = 1`、`i = 0.1`，
  5025 行里 96.84% 贴死积分限幅，数据右截断；不是模型错，也不能复用那批数据标定

## 5. 标定流程（下次上板）

前置：新固件已烧录，`pitch_gravity_enabled = false`，先采一份"前馈关闭"基线。

1. ANGLE 模式，绝对角阶梯 -20 / -15 / -10 / -5 / 0 / +5 / +10 / +15 / +20 度，每档保持 3 s
2. 每档采样：`gimbal.pitch.angle_deg`、`gimbal.pitch.output_current_a`、
   `gimbal.pitch.target_speed_rad_s`、`gimbal.pitch.speed_rad_s`、`gimbal_internal.pitch.speed_pid.i`
3. 稳态判据：`|target_speed_rad_s| < 0.02 rad/s` 且 `speed_pid.i` 相邻采样不再变化，取该段均值
4. 上行扫一遍、下行扫一遍，同一角度取平均，抵消静摩擦迟滞
5. 记录的是**实际角** `angle_deg`，不是下发目标角；积分饱和导致轴下垂时两者不等
6. 拟合 `i = a·cosθ + b·sinθ + c`，换算 `A = hypot(a, b)`、`θ₀ = atan2(b, a)·180/π`、`i₀ = c`
7. 残差自查：残差 RMS 应接近电流量化（±3 A 对应 ±16384，约 0.18 mA）加静摩擦散布；
   若某个角度残差明显，先检查该点 `speed_pid.i` 是否贴到 1.4
8. 写入：EmberProbe 写 `gimbal.config.pitch_gravity_*`，写入后下一周期即生效；
   **必须同时满足 `A + |i₀| ≤ 1.0`**，否则整份配置判非法，两轴一起进故障
9. 验收：仅在 `enabled` 开关上做 A/B，比较同角度静止时的角度误差与电流、以及 ±10° 阶跃的上升时间和超调

## 6. 防御性检查自查

本次新增的检查全部集中在 `Gimbal_IsPitchGravityConfigValid`，属于**在线调参信任边界**，

| 检查 | 类型 | 上游是否已检查 |
|---|---|---|

| `isfinite(i₀)`、`|i₀| <= max_current_a` | 在线调参 | 否，同上 |
| `A + |i₀| <= max_current_a` | 在线调参（最坏叠加） | 否，同上 |

- 未新增判空：`config` 由 Control 入口保证非空，`Gimbal_CalcPitchGravity` 只在该校验通过后调用

## 9. 标定工具

`tools/pitch_gravity_fit.py` 读取 EmberProbe 导出的 CSV，离线输出 A、θ₀、i₀ 与残差，
不连接探针、不写目标板

```bash
py tools/pitch_gravity_fit.py data/emberprobe-live-<时间戳>.csv --outdir docs/validation
```

处理流程：

1. 列名归一化：剥离 ` [f32]`/` [u8]` 类型后缀，处理 UTF-8 BOM，时间列支持 ISO 8601 与纯数字秒
2. 稳态筛选：`gimbal.pitch.state == 1`、`gimbal.mode == 2`、`gimbal.config_valid == 1`、
   `|target_speed_rad_s| <= 0.02`、`|speed_rad_s| <= 0.05`
3. 分段：按目标角切段（1° 滞回吸收目标抖动），再按运动方向切段，
   保证转向点上行末段与下行首段不会混在一起
4. 稳态窗口：按时间丢弃进入稳定后的过渡段（默认 1 s，超过段长一半时自动截半）
5. 同一目标角的上行与下行取平均，抵消静摩擦迟滞，并输出两点差值作为迟滞量
6. 最小二乘拟合 `(a, b, c)`，同时给出协方差换算的参数标准误差

输出：

- 控制台：逐点表格、拟合系数、`A ± σ`、`θ₀ ± σ`、`i₀ ± σ`、区间内最大预测偏差、R²、条件数
- `<stem>_pitch_gravity_fit.json`：全部数据与残差
- `<stem>_pitch_gravity_fit.svg`：散点、迟滞竖线、拟合曲线（无 matplotlib 依赖）

常用选项：`--fix-angle-deg 12` 固定相位退化为两参数拟合（行程短时更稳）、
`--settle-s`、`--sign -1`、`--no-svg`

### 10.1 机械限位窗口是动态的

`Gimbal_RunAxis` 在 `mechanical_limit_enabled` 时用
`min = angle_deg + min_limit - mechanical_angle_deg` 夹住世界系目标，窗口边界等于
`(world - mechanical) + 限位`，只取决于当时底座姿态。标定期间底座倾角从 3.44° 漂到 5.46°，
世界系可达窗口随之在 [−16.6, +23.4] 与 [−14.5, +25.5] 之间移动

命令角落在窗口外时 `mechanically_limited` 恒为真，该分支每周期清空速度环积分
（`PID_ResetIntegral`），轴无法建立保持电流而被静摩擦卡住：命令 −16° 时轴停在 −11.03°，
电流只有 −0.276 A。**标定命令必须落在窗口内，且不能贴边**

### 10.2 静摩擦与重力分离

同一角度从上方逼近（下行）和从下方逼近（上行）的保持电流相差约 0.25 A，
即 2 倍库仑摩擦力矩；两者平均即为重力负载：

| 世界角 | 下行电流/A | 上行电流/A | 平均（重力）/A |
|---|---|---|---|
| −8° | −0.576 | −0.381 | −0.479 |
| 0° | −0.554 | −0.290 | −0.422 |
| 8° | −0.584 | −0.327 | −0.456 |
| 16° | −0.618 | −0.300 | −0.459 |
| 20° | −0.566 | −0.333 | −0.450 |

重力负载在 −14…+22° 内落在 −0.40…−0.48 A，**基本恒定**，没有可分辨的 cos 形状

### 10.3 为什么拟合不出 A 和 θ₀

联合回归 `I = a·cosθ + b·sinθ + c + s·f`（s = 下行 +1、上行 −1，f 为摩擦半带宽）：

| 量 | 结果 |
|---|---|
| A | 1.69 ± 1.06 A |
| θ₀ | −0.5 ± 4.0° |
| i₀ | −2.11 ± 1.05 A |
| 摩擦半带宽 f | 0.127 A |
| R² / RMS | 0.667 / 0.088 A |
| 归一化条件数 | 128 |

失败原因有三条，都不是工具问题：

1. 静摩擦使单点保持电流有 ±0.15 A 不确定度，而 ±20° 行程内 cos 幅值总变化只有 0.03 A，
   信噪比约 1:5
2. 纯 P 角度环下速度环积分不是由负载唯一决定的，同一角度存在多个积分平衡点，
   观测到 8° 处上行电流 −0.327 A、下行 −0.255 A 与 −0.584 A 并存
3. A 与 i₀ 强共线，解出的 A+|i₀| = 3.8 A 超过 `max_current_a` = 1.0 A，
   就算接受这组数也写不进配置（写入会被 `Gimbal_IsPitchGravityConfigValid` 拒绝，两轴转故障）

### 10.4 采用的标定值

在 ±20° 机械行程内重力近似常数，取物理意义上退化最小的形式：

```text
A = 0.45 A，θ₀ = 180°  →  i_ff = 0.45·cos(θ - 180°) = -0.45·cos θ
i₀ = 0
A + |i₀| = 0.45 ≤ max_current_a = 1.0   通过配置校验
```

θ₀ = 180° 表示按 `A·cos(θ - θ₀)` 参数化时重力前馈在 θ = 180° 处取得最大正值，
等价于"θ = 0°（臂水平）处需要最大负向补偿"，与实测符号一致

### 10.5 A/B 验证

同一角度、同样从上方逼近，读稳态总电流与速度环积分（ki = 0.5，积分贡献 = 0.5·i）：

| 目标角 | 前馈前 i | 前馈后 i | 积分占 i_limit(1.4) | 前馈前总电流/A | 前馈后总电流/A |
|---|---|---|---|---|---|
| 22° | −1.146 | −0.475 | 89% → 34% | −0.573 | −0.613 |
| 16° | −1.237 | −0.384 | 88% → 27% | −0.618 | −0.619 |
| 8° | −1.203 | +0.360 | 86% → 0 | −0.584 | −0.255 |
| 0° | −1.119 | −0.119 | 80% → 8% | −0.555 | −0.500 |
| −8° | −1.164 | −0.181 | 83% → 13% | −0.576 | −0.622 |

结论：总电流基本不变（重力负载没有变），积分占用从 80-89% 降到 0-34%，
速度环可用积分余量从约 0.16 A 恢复到约 0.92 A。前馈的实际收益是**恢复积分余量，
让轴在大量程和大电流下不再依赖接近饱和的积分维持姿态**，而不是修正角度曲线

8° 一栏前馈后积分反号，是该角度的另一个静摩擦平衡点，不是前馈方向错误；
符号正确性由 5 个点中有 4 个积分绝对值下降 60-90% 共同支持

## 11. 恒速正反向扫掠（第二次上板，14:03-14:14）

目的：用符号确定的动摩擦替代静摩擦，正反向在相同角度平均后完整抵消摩擦项，

### 11.1 SPEED 模式恒速方案失败

速度环刚度不够，无法做恒速跟踪：

- P 增益只有 `k·p` = 0.45 A/(rad/s)，0.03 A 的电流误差就对应 0.067 rad/s 的速度误差
- 行程内负载变化约 0.03 A，于是轴持续加速：目标 0.04 rad/s，实测爬到 0.052、0.108，
  最后冲到上边界 25.01°（`mechanically_limited` 清积分，i 归零）
- 积分爬升速率 `di/dt = k·err`，实测 12 s 只建立 0.1 A，远跟不上负载变化
- 把 `speed_pid.i` 临时提到 2.0 无效，问题在 P 刚度不在积分速度
- 失败数据留档：`pitch_gravity_constspeed_20261117.csv`
