# yaw 恢复误撤目标与遥控迟滞修正

日期：2026-10-28

状态：软件回归、Debug 构建、严格 ARM 检查及 ARCH/HW/SPEC 通过；未连接探针、未烧录、未运行真实电机，现场效果待验证

用户报告 `620e751` 放下后仍发软，遥控有反应但不如原先顺畅。本记录替代上一版恢复判据、低速附加阻尼及常驻电流斜坡约定，保留保护时放弃旧目标、捕获当前姿态再恢复的用户选择

## 软件问题证据

旧版 RESTORING/GUARDED 在单周期 `abs(x)>=0.2 rad/s` 时立即收回权限并再次跟随当前姿态。GM6020 转速反馈使用整数 rpm，1 rpm 约为 0.10472 rad/s；编码器与 IMU 还存在不同步和噪声，单点差值不能直接当作持续底座运动

回归让已恢复的云台产生 5 度姿态误差，每 100 ms 注入一个持续 2 ms 的 3 rpm 残差脉冲，并叠加 IMU 小噪声。旧版目标由 0 改成 5 度，1500 周期全部处于 HOLD，最终电流仅约 0.00297 A；相同测试链接本轮实现后，目标保持 0，未退回 HOLD，纠偏电流可达到配置的 0.5 A 上限。此反例证明旧软件存在误撤目标路径，不等于已确认现场所有原因

另外，旧版在正常 MONITOR 和完整闭环 GUARDED 阶段也永久施加 2 A/s 电流斜坡，从 0 增至 0.5 A 至少需要 0.25 s。低速残差还始终叠加阻尼，持续改变正常 PID 输出并触发积分反算。这些处理会额外拖慢响应或形成控制偏置

历史采样仅作为量化与残差背景，未用作本轮同步实测或接地证明

## 修正行为

仅修改 `User/module/gimbal_governor.c`，不新增结构体或字段，不修改用户 PID、遥控灵敏度、任务、BSP、设备驱动和 CubeMX

残差仍为编码器相对转速减上部惯性 yaw 转速加独立底盘实测转速，本轮底盘项仍取 0

- 恢复判据与低速包络使用时间常数 40 ms 的一阶残差滤波，权重为 `dt/(0.04+dt)`；PID 两环反馈保持原样
- RESTORING/GUARDED 中，滤波残差达到 0.2 rad/s 连续 40 ms 才退 HOLD；超过 0.4 rad/s 立即 BRAKING
- HOLD、RESTORING、GUARDED 保留原始残差快速通道，`abs(x)>=1 rad/s` 立即 BRAKING，不等待滤波或持续确认
- BRAKING 继续使用原始残差制动；滤波残差小于 0.2 且原始残差小于 0.4 rad/s 连续 0.1 s 才进入 HOLD
- HOLD 中滤波残差小于 0.15 rad/s 连续 0.3 s，捕获当前姿态并进入原有 0.5 s 渐进恢复
- GUARDED 保留完整串级 PID 和新遥控命令，原始残差小于 0.4、滤波残差小于 0.15 rad/s，且编码器和 IMU 同向、上部速度大于 0.1 rad/s、滤波残差小于上部速度的 25%，连续 0.2 s 后进入 MONITOR
- 低速包络在滤波残差不超过 0.2 rad/s 时不附加阻尼；超过后仅对超出部分施加阻尼，0.2～0.4 rad/s 的连续撤驱包络保留
- MONITOR/GUARDED 取消常驻电流斜坡，正常残差区内速度请求和配置限幅内的 PID 电流原样通过；起控、制动、跟随和渐进恢复仍限制电流变化
- RELAX、初始化和无效反馈清除滤波历史及复发计时，无效反馈不能用于主动制动

保护状态仍由原显式状态机统一推进。真实故障、失联、遥控超时、输出发布失败的零输出和人工恢复联锁保留；pitch 独立控制，机械边界具有最终否决权；速度积分继续限步长反算，不直接清零

静止可以停留 GUARDED，但正常区域中的电流及速度请求完整通过，不以必须退出监护作为恢复操控的前提。本轮没有增加接地检测，安静窗口仍只允许试行恢复

## 探索失败与验证边界

最初只增加残差滤波、继续保留小残差阻尼的中间试验未通过：0.06 A 阻力模型在 30 s 后约偏离 -7.9217 度，因此没有提交该版本。当前实现同时取消正常区域附加阻尼和常驻电流斜坡，并补充电流原样通过的断言

正常闭环恢复原 PID 响应后，模型最大单步电流约 0.079 A，不能继续声称所有阶段每周期均小于 0.004 A；测试改为检查配置边界，并独立检查正常响应完整通过。起控及保护阶段的斜坡约束继续保留

滤波与持续确认会延后对中小残差的响应，本轮悬空合成模型峰值较上版约 0.218 rad/s 增大；原始大残差快速通道用于避免严重运动继续等待。模型参数未经过实物辨识，不能据此核定真实峰值、制动距离、机械稳定性或遥控手感

本次仅软件验证。四轮实际反馈经底盘运动学解算旋转速度、结合遥控指令判断运动意图的后续思路保留；未接入独立底盘转速，小陀螺及底盘跟随兼容仍未完成
