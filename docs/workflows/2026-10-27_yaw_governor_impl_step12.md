## 问题与实施结果

悬空握住上部时，yaw 电机力矩可以带动底座反转，而上部 IMU 转速接近零。惯性闭环继续要求出力，原机械超速保护又将 yaw 锁成 FAULT，遥控任务随之撤销两轴使能

本轮删除这项运动超速 FAULT 判据，用无跨周期状态的连续电流包络收紧驱动并增加反向制动。包络只作用于 yaw，不改变原状态机及遥控故障联锁，pitch 正常闭环

### 残差与坐标

```text
x = motor_speed_rad_s - imu_yaw_speed_rad_s + independent_chassis_speed_rad_s
```

- 三项均为同一正方向，单位 rad/s
- 编码器转速取已完成 `reversed` 换算的 `axis->motor_speed_rad_s`
- 上部惯性转速取模块按 ZYX 欧拉运动学换算的 `axis->speed_rad_s`，不直接使用机体系 Z 分量或三轴模长
- 本轮独立底盘实测转速显式传 `0.0f`，不使用同源 `base_speed_rad_s`，避免代数抵消残差
- 例如编码器和上部惯性转速均为 20 rad/s 时残差为 0，不单凭编码器幅值触发限速
- 本轮小陀螺及底盘跟随兼容尚未完成，独立转速来源、坐标、采样同步及倾斜误差仍待后续处理

### 电流包络

`I_max` 为轴配置电流上限，`I_brake=min(0.3 A,I_max)`。初始残差阈值为 `W_soft=8`、`W_hard=12`、`W_brake=16 rad/s`，均为待实测值

| 残差区间 | 正向电流上界 upper(x) |
| --- | --- |
| x <= 8 | I_max |
| 8 < x < 12 | I_max × (12 − x) / 4 |
| 12 <= x < 16 | −I_brake × (x − 12) / 4 |
| x >= 16 | −I_brake |

```text
lower(x) = -upper(-x)
candidate = Clip(speed_pid_output, -I_max, I_max)
governed = Clip(candidate, lower(x), upper(x))
actual = 机械边界阻断后的 governed
```

正负方向镜像，包络各边界连续。候选电流已有更强的反向制动时保留原值，不以较弱的制动上限覆盖。包络连续不代表任意突变的输入或反馈都会产生时间连续电流

包络在速度环限流后、机械行程电流阻断前执行，机械边界仍有最终否决权。非有限反馈、残差或反算结果交回原故障停机路径，不使用旧转速继续制动

### 积分处理与目标保持

仅当最终实际电流与候选电流不同时执行本轮抗饱和：

1. 速度环当周期误差积分增量若与 `actual-candidate` 方向相反，撤销该增量，保留反向退饱和增量
2. 速度环按下式反算，`i` 为现有误差积分，`Ki` 为积分项增益，不额外除以 `k`
3. 角度环只撤销继续推向受限方向的当周期积分增量，保留既有积分和反方向增量，原机械边界积分回退保留
4. 限速不清零两环积分、不改变 `target_angle_deg`、不将姿态目标跟随到当前姿态，遥控主动输入及正弦测试仍按原流程推进目标

```text
tracking = min(dt / 0.05 s, 1)
delta_I = Clip((actual-candidate) × tracking, -2 A/s × dt, +2 A/s × dt)
i_next = Clip(i + delta_I / Ki, -i_limit, +i_limit)
```

`Ki <= 0.000001` 时保留积分、不做除法，阈值与现有 PID 一致。限制的是反算造成的积分电流贡献变化，正常 PID 积分增量及原机械边界回退不受此变化率约束

反算使用机械边界之后的实际电流，避免边界阻断制动后仍按未执行的电流调整积分。真实故障、RELAX、失联与模式切换中的历史清除逻辑继续保留
