# 云台单轴反馈超时自动恢复

## 需求与授权

- 用户确认单轴反馈超时后只停止该电机，保持右拨杆上位时，反馈恢复后自动运行，无需重新拨回中位
- 用户已确认允许修改 `User/module/gimbal.c`、`gimbal.h` 及 `User/task/motor_gimbal.c`、`motor_gimbal.h`
- 不新增结构体或修改字段，不修改用户 PID 配置、BSP、设备驱动、CubeMX、通信任务或硬件资源
- 为排查原因增加的临时诊断仍保持撤销；接口松动仍是未证实的现场判断

## 实现行为

- 保留 `RELAX=0`、`RUNNING=1`、`FAULT=2`，追加 `OFFLINE=3`
- 无新帧但缓存未超过原有 90 ms 阈值时保持原状态；反馈超时或有效新帧与上一参考间隔超时时，运行轴转为 OFFLINE
- 失联入口立即撤销该轴输出、清空两环历史、丢弃旧机械连续角；另一轴继续控制，不撤销遥控使能
- 等待期间该轴持续零电流，任务仅对 RUNNING 轴积分遥控目标，因此不会积累失联轴目标及速度
- 有效机械反馈重新建立且运行请求、共用惯性反馈、配置和控制周期合法时，复用原起控路径恢复
- ANGLE 恢复首周期捕获当前 INS 姿态并清零前馈，清空两环历史并预置速度环微分；后续周期重新采纳摇杆输入
- 运行请求撤销时转回 RELAX；遥控失联、共用 IMU 故障、非法反馈、重复或倒退时间戳、连续角歧义、配置及计算异常仍沿用锁存保护
- 零点或方向在 OFFLINE 期间改变也进入 FAULT，已有 FAULT 不得被后续超时事件降级为 OFFLINE
- 若新帧到达时才发现上一参考已超时，先进入 OFFLINE 并丢弃旧参考，下一有效新帧重新建角后恢复
- 机械限位在恢复时继续生效；当前 yaw 未开启机械限位，连续角重新建参考不能恢复断流期间丢失的圈数，姿态目标继续使用 INS 累计角
