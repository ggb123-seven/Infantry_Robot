# yaw 悬空疯车修复与底盘旋转兼容方案

状态：方案待评审，未实施。用户明确要求先写方案，不修改代码

## 1. 本轮目标与现场条件

用户确认的操作是整套云台悬空拿起，yaw 电机带着下方底座转

本轮优先解决这种条件下机械端被持续加速的问题，同时保留后续小陀螺、底盘跟随的接入路径。用户已经否定“机械运动保护触发 FAULT，再让 yaw、pitch 一起 RELAX”的效果

目标行为：

- 正常工况继续使用惯性姿态闭环稳向，不把云台长期改为相对底盘定角
- 机械端超出允许运动范围时，yaw 受限减速，健康 pitch 继续闭环
- 不因单纯机械转速较大或编码器与 IMU 转速不同而联动两轴 RELAX
- 受限时同步处理积分，避免解除约束后由旧积分再次加速
- 小陀螺和跟随允许的底盘旋转必须进入正常运动范围的计算
- 遥控失联、IMU 无效、机械反馈无效等真实异常继续走明确的安全路径

这里的“解决疯车”指消除持续加速到空载高转速的失控行为。拿住上部且仍要求追踪旧姿态时，底座完全静止与保持原姿态目标不一定能够同时实现；不能把限速写成自动搬运识别或完全静止保证

## 2. 当前证据与根因链

已有历史见 `2026-10-27_yaw_lift_analysis.md` 和 `../validation/yaw_lift_20261027_extended.json`

- 编码器转速曾达到约 ±356 rpm，上部 IMU 角速度同时较小
- 一个峰值点的姿态误差约 7.53°，惯性速度目标约 1.97 rad/s，机械转速约 36.97 rad/s
- 同一点保存积分贡献约 0.429 A，电流指令达到 0.5 A
- 电机相对角度变化与转速积分吻合，支持实际机械旋转

拿住上部后，电机力矩主要带动自由底座反转。惯性速度环继续看到上部速度不足，因此比例项和既有积分仍可持续出力。0.5 A 限流和惯性速度目标限幅都不等于机械转速限制

当前追加的保护只把这种运动转成 FAULT，再由任务联停两轴；它没有形成机械速度负反馈制动，也会限制正常底盘旋转。将它删除而不补控制约束，会重新暴露原问题

历史 CSV 是异步多变量采样，不是同一控制周期的原子快照；旧记录没有逐点固件 SHA。本轮不借历史数据断言当前板上触发了哪一个具体分支

## 4. 推荐控制结构

```text
惯性姿态目标 -> 角度环 -> 惯性速度目标 + 前馈 -> 惯性速度环 -> 候选电流
                                                                  |
编码器机械速度 + 独立底盘运动信息 -> 允许运动包络 -> 电流约束与主动制动
                                                                  |
                                                       最终 yaw 电流 -> CAN
```

两条支路测量不同的运动。惯性闭环负责上部稳向，机械约束负责限制电机对相对运动持续注入能量。编码器不替换正常惯性速度反馈

### 4.1 连续约束替代机械超速锁存

正常允许范围内保持原姿态控制输出。接近机械运动边界时，连续收紧该转动方向上的加速电流；达到边界后禁止继续同向驱动，越界后施加受限反向电流

模块统一正方向后，应满足：

- 正向越界时，约束电流上限，使最终电流为零或负值
- 反向越界时，约束电流下限，使最终电流为零或正值
- 已有更强的反向制动请求优先保留，不被弱制动值覆盖
- 制动电流始终受现有电流上限和单独核定的制动上限约束
- 反装方向在既有输出转换处统一处理，不在保护逻辑里再次取反

可评审的连续曲线为：正向电流上界随正向机械速度递减，在边界处降到零，越界后下降到负的制动上限；反向采用镜像曲线。需留出能覆盖正常加速和跟随瞬态的过渡带

电流反向不等于任意机械条件下都能按固定时间停转。电流方向必须在低速实物测试中验证，并量测峰值速度、制动时间及回弹

不继续使用“机械转速幅值大于 IMU 三轴模长加 6 rad/s”作为故障或搬运识别条件。现有 12 rad/s 也只作为历史调试数值，不直接认定为整车可用阈值

### 4.2 积分与目标处理

以实际施加的电流约束结果处理积分，不能仅依靠 PID 内部自己的输出限幅：

- 机械约束生效时，拒绝继续积累推动机械端越界的速度积分，并释放该方向已有积分
- 角度外环同时禁止向受限方向继续积累积分，保留有助于减速或离开约束区的修正
- 普通控制周期继续保持既有姿态目标，不能每周期重置目标来掩盖问题
- 解除约束时平滑恢复出力，不能把旧积分一次性放回
- 不把“停止更新目标”和“清除已有姿态误差”混为一谈

正常小陀螺和跟随过程中，不自动把惯性目标改成当前姿态，否则会改变瞄准方向。若用户后续要求搬运时底座完全停转，应单独设计明确的搬运命令及目标交接，不在本轮自动推断

### 4.3 状态与恢复

建议使用独立、显式的运动约束状态，状态名称在实施时评审；以下是行为草案，不新增或定稿结构体

| 状态 | 入口动作与周期动作 | 退出与异常处理 |
| --- | --- | --- |
| 正常控制 | 运行惯性闭环，监视机械运动包络 | 接近约束进入限速；真实故障沿用安全状态 |
| 限速制动 | 保持运行使能，约束 yaw 电流，处理受阻积分，pitch 继续运行 | 进入内侧释放边界并持续满足释放条件后进入恢复 |
| 平滑恢复 | 以无旧积分冲击的方式逐步释放约束 | 稳定后正常控制；再次越界立即限速 |

停止命令在所有状态下立即生效。反馈非法、失联或超时后，不沿用最后转速主动反向制动；默认零电流并交给既有故障/离线流程。非法约束状态必须有零输出的 default 分支

释放阈值、持续时间和制动电流均为待验证参数。限速不是 FAULT，不能因此触发任务中“任一轴故障导致两轴 RELAX”的分支

## 5. 小陀螺与底盘跟随的兼容条件

### 5.1 不用同一份反馈循环证明自己

水平底盘、轴向一致且运动较小时，有近似关系：

`上部惯性 yaw 速度 = 底盘惯性 yaw 速度 + yaw 编码器相对速度`

若云台稳向不转，底盘以 +8 rad/s 旋转，编码器出现约 -8 rad/s 是正常补偿。此处 +8 只是说明物理关系的例子，不是批准的整车速度

现有 `base_speed_rad_s = speed_rad_s - motor_speed_rad_s` 可作观测，但不能再把它当作独立底盘测量来放宽保护。悬空反转时它同样会得到较大的“底盘速度”，这样会恰好放过需要抑制的运动

### 5.2 独立的底盘旋转信息

后续小陀螺、跟随启用前，需要给云台提供有时效和有效性判断的底盘运动依据：

1. 优先评估使用四轮实测输出轴转速和底盘几何参数反解底盘 yaw 速度
2. 底盘模式、转向命令用于核对允许工况，不能把命令 wz 直接当成实测 rad/s
3. 正常允许机械速度需要包含云台转动要求、底盘实测转动及反馈延迟/瞬态余量，并覆盖正反向叠加
4. 底盘速度输入失效时，回到明确的保守包络；不能沿用旧的大速度无限期放宽

四轮里程计存在轮胎打滑、架空和几何误差，不能独立证明底盘真实转动；高精度或更宽工况可再评估底盘 IMU。仅为当前问题不默认增加硬件

当前底盘接口仅有归一化运动向量和轮速尺度，源码中没有可直接采用的轮径、轮心到旋转中心距离及经过验证的真实 yaw 速度。因此本轮方案不能承诺任意小陀螺速度都与保护无冲突

初次云台修复只在明确的底盘静止/测试包络内验收。小陀螺和跟随启用前，完成独立底盘运动输入与整车包络验证；不能通过检测“下位档”就完全关闭保护

### 5.3 跟随控制的后续接法

- yaw 编码器角度减机械正前方零点，经单圈最短误差环绕后得到云台相对车头角
- 跟随模式由底盘 PID 使该误差趋近零，产生底盘转向速度
- 小陀螺模式自行产生底盘转向速度，退出跟随转向 PID 的输出，防止两个控制器对抗
- 两种模式均可按相对 yaw 角旋转平移向量，保持操作方向与云台一致
- 云台的惯性目标继续由云台输入更新，不用底盘跟随误差改写该目标
- 跟随与小陀螺切换时清理相应积分并平滑转向；相对角失效时执行底盘侧的明确降级

相对角、独立底盘速度等跨任务数据使用快照/邮箱传递，不裸读其他任务正在修改的全局结构体，不争抢现有单消费者邮箱

## 7. 验证与验收清单

### 软件验证

- 使用真实 Gimbal、PID 及任务解析代码，回放历史中小惯性速度、大机械速度和积分残留的条件
- 验证机械转速越界时电流不再向越界方向加速，主动制动电流有界；正反转、反装方向和 ANGLE/SPEED 都覆盖
- 验证受限积分释放、边界附近反复波动、持续不可达姿态及多轮进入/退出，检查没有解除后电流突跳
- 验证 yaw 限速期间遥控保持使能，pitch 目标和输出保持独立；真实故障仍执行原安全路径
- 验证正常底盘转速与云台补偿组合时约束不介入；不能只测 IMU 与编码器同速的情况
- 覆盖小陀螺正反转、跟随转向、松杆、模式切换、底盘速度输入延迟/失效，以及云台/底盘同时转动
- 检查运动包络、输入时效及非法状态，运行实际 ARM 严格编译、Debug 构建和 ARCH/HW/SPEC 门禁

旧 CSV 的逐点回放只能验证输出约束和状态逻辑，不能证明施加制动后真实速度已下降。简化动力学仿真也不能替代实物停转测试

### 实物验收

- 托底座、拿上部及放回三个工况分别标记，记录实际旋转部件
- 低速确认反向电流确实降低机械相对转速，再逐步测正反向制动
- 记录机械峰值速度、制动介入时间、减速时间、最大电流、回弹和反复恢复次数
- 整车小陀螺和跟随分别记录底盘实测转速、yaw 相对速度、惯性姿态误差及约束状态
- 覆盖真实遥控失联、单轴反馈失联和 IMU 异常，不通过关闭保护来换取测试通过

峰值速度和停止时间的具体合格数值待速度包络、电流限制及机械惯量核定后确定，未测量前不宣称疯车已经解决
