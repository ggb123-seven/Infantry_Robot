# 遥控旋转模式与云台悬空保护兼容方案

日期：2026-10-28

状态：仅方案，用户明确要求暂不修改源码；下列接口、模式与状态转换均未实施

## 问题与当前实现

`User/module/gimbal_governor.c` 使用编码器相对转速减上部 IMU yaw 转速作为残差，独立底盘转速项固定为零。底盘主动旋转和悬空时底座反转均可产生该残差，现有反馈无法独立区分两者

`User/module/cmd.c` 当前左拨杆映射为：上位平移且 wz=0，下位平移并叠加归一化 wz=+0.30，中位及非法值停机。底盘控制器当前只有 RELAX、INDEPENDENT，尚未实现底盘跟随

云台右拨杆的中位确认、上位使能、遥控失联与真实故障后的人工恢复流程保持现有约定

## 建议行为

按有效遥控快照识别旋转意图，限制低速残差悬空保护的适用范围，不再仅凭残差区分主动旋转与悬空

| 模式意图 | 来源 | 低速残差保护 | 备注 |
| --- | --- | --- | --- |
| NONE | 左拨杆上位或中位 | 沿用现有检测、制动和自动恢复 | NONE 表示没有主动旋转意图，不表示实测停稳 |
| SPIN | 左拨杆下位且遥控有效 | 暂停低速异常累计、复发判断和低速撤驱包络 | 允许正常旋转产生的残差 |
| FOLLOW | 后续底盘跟随命令 | 预留与 SPIN 相同的旋转意图入口 | 本轮不映射拨杆，不实现跟随闭环 |
| UNKNOWN | 非法模式、无快照、离线、超时或时间回退 | 不给予旋转豁免 | 遥控无效仍按原流程两轴待机 |

旋转模式保留配置电流上限、目标速度上限、机械行程否决、反馈时效、非有限值检查和真实故障停机。现有 8/12/16 rad/s 的高残差电流包络也保留，本方案只限制低速悬空判据；高残差包络与实际小陀螺速度范围的兼容性须单独验证

遥控模式只能说明运动意图，不能证明底盘接地。SPIN 或未来 FOLLOW 下若发生真实悬空，低速残差保护同样受到上述限制；本方案不具备旋转模式中的独立悬空识别能力

## 接口与消息流建议

本方案使用枚举和函数参数，不新增或扩展结构体。以下名称为建议，尚未定稿

- 在 `User/module/gimbal.h` 定义 `Gimbal_ChassisMotion_t`，包含 NONE、SPIN、FOLLOW、UNKNOWN
- 在 `User/module/cmd.h/.c` 提供纯解析接口 `Cmd_ParseChassisMotion(rc, rc_valid, now_us)`，统一拨杆映射与 100 ms 帧龄校验，不访问队列或跨任务全局变量
- 增加 `Gimbal_ControlWithChassisMotion(gimbal, command, chassis_motion, period_s)`，将本周期模式沿参数传入 governor；原 `Gimbal_Control()` 保留并以 NONE 调用新入口，兼容现有调用方
- `User/task/motor_gimbal.c` 使用本任务已有 DR16 缓存，同时生成云台命令和底盘旋转意图；先读取快照，再采时间，两种解析共用同一时间值
- governor 在原状态机内集中处理模式变化，禁止任务层直接修改保护状态、PID 积分或电流

数据流为：DR16 独立云台邮箱 → 云台任务缓存 → 命令层解析 → 云台模块 → governor 状态机 → 原电流输出链

不读取另一个任务的 `chassis_command`，不新增 ISR 共享数据、RTOS 对象或临界区。跟随入口未来必须由有效命令来源按周期显式传入，不能通过永久布尔开关放行

FOLLOW 在本方案中仅代表未来底盘主动跟随云台的旋转意图。实际跟随所需的 yaw 相对角、零点、旋转方向、控制器和输出限幅留待后续设计；不直接把 FOLLOW 送入当前仅接受 INDEPENDENT 的底盘控制器

## 模式切换与保护状态交接

1. 进入 SPIN 或未来 FOLLOW：清除低速残差累计、滤波和复发历史，解除由该残差判据引起的制动、保持和监护约束；保留真实 FAULT 与 OFFLINE 行为
2. 若切换前处于 BRAKING、HOLD 或 RESTORING，先捕获当前 yaw 并清零前馈，再走渐进恢复，避免追赶已撤销的旧目标；原本正常闭环的姿态目标保持连续
3. 旋转模式持续期间不重复初始化、不重复捕获姿态，不因每周期解析而重启恢复斜坡；保护状态与运动意图由 governor 集中管理
4. SPIN 与 FOLLOW 互切属于同类旋转意图，不重复撤目标或重启渐进恢复
5. 退出旋转模式：清除旋转期间的低速残差历史，从当前反馈重新累计非旋转异常；恢复现有 0.15 s 检测规则，不增加额外盲区延时，高残差包络持续有效
6. 遥控失联、RELAX、无效周期及真实故障仍优先执行现有安全路径；非法旋转枚举不得提供豁免
7. 模式切换不直接清空 PID 积分，沿用最终执行电流的限步长反算；渐进恢复保留切换前实际电流历史并服从当前配置限幅
