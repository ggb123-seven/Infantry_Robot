# 遥控旋转模式与云台悬空保护兼容方案

日期：2026-10-28

状态：后续已获用户授权并接入四轮联合识别链路，生产换算系数仍为零，等待用户提供尺寸后标定启用

实施结果、实际接口及验证边界见 [实施记录](2026-10-28_chassis_motion_governor_impl.md)。本文保留方案推导与旧版备选供追溯，接口建议以实施记录和当前源码为准

## 问题与当前实现

`User/module/gimbal_governor.c` 使用编码器相对转速减上部 IMU yaw 转速作为残差，独立底盘转速项固定为零。底盘主动旋转和悬空时底座反转均可产生该残差，现有反馈无法独立区分两者

`User/module/cmd.c` 当前左拨杆映射为：上位平移且 wz=0，下位平移并叠加归一化 wz=+0.30，中位及非法值停机。底盘控制器当前只有 RELAX、INDEPENDENT，尚未实现底盘跟随

云台右拨杆的中位确认、上位使能、遥控失联与真实故障后的人工恢复流程保持现有约定

## 当前首选：遥控意图与四轮运动一致性联合识别

用户追加要求研究旋转模式中的识别办法，因此将原先“旋转时暂停低速保护”降为简化备选。当前首选保留旋转期间的异常识别，使用独立四轮实测反馈补偿正常底盘旋转

### 现有数据依据

- `gimbal.c` 已计算 `base_speed_rad_s = yaw.speed_rad_s - yaw.motor_speed_rad_s`，表示底座水平、关节共轴条件下估计的底座角速度
- `CANDevices_Snapshot_t.actual_speed_rpm[4]` 已提供四轮输出轴实测转速，可作为独立于 yaw 编码器和上部 IMU 的轮速观测
- `Mixer_Apply()` 的 OMNICROSS 四轮旋转项同号，前后及左右平移项求和抵消；正确轮序和方向下，旋转轮速分量为四轮 rpm 的平均值
- 当前混合器仅处理归一化运动，没有轮径、有效旋转力臂等物理几何参数；平均 rpm 换算车体 rad/s 需要实测尺寸或已确认接地条件下的独立标定
- CAN 聚合快照未发布四轮各自源时间和实测电流；`applied_current_a` 是下发命令，不可作为实测负载。M3508 现有 `torque_current` 还包含既有协议标度和减速比变换，不得直接当作转子安培值使用

### 核心计算

在底座近水平、yaw 关节共轴、轮子无显著打滑的适用条件下：

```text
底座角速度估计 = 上部 IMU yaw 转速 − yaw 编码器相对转速
轮速车体角速度估计 = K_wz × (n1 + n2 + n3 + n4) / 4
一致性残差 = yaw 编码器相对转速 − 上部 IMU yaw 转速 + 轮速车体角速度估计
```

`n1～n4` 为方向已核对的输出轴实测 rpm，`K_wz` 单位为 rad/s 每 rpm。对称切向全向轮布局中，可由轮半径与有效旋转力臂计算该系数；具体公式以实物安装几何为准，不将当前归一化 wz=0.30 直接当作 rad/s

补偿项来自独立四轮测量。禁止使用 `base_speed_rad_s` 自己抵消原残差，也禁止在未知接地状态下在线调整 `K_wz` 把残差拟合到零

| 典型工况 | 轮速推算旋转 | 底座旋转估计 | 识别结果 |
| --- | --- | --- | --- |
| 接地正常小陀螺 | 与底座运动相符 | 与轮速运动相符 | 一致性残差小，保持云台正常闭环 |
| 轮子架空空转、车体未相应转动 | 显示旋转 | 很小或明显不符 | 一致性异常，进入可疑状态 |
| 底座受云台反作用力旋转、轮子未相应运动 | 很小或不相符 | 显示旋转 | 一致性异常，进入可疑状态 |
| 打滑、碰撞或轮子受阻 | 可能明显不符 | 可能明显不符 | 同样视为运动异常，不强行归因悬空 |
| 悬空时两路恰好一致 | 与底座运动相符 | 与轮速运动相符 | 无法仅靠本组观测确定接地 |

遥控模式及底盘最终命令用于识别主动旋转、启停和跟随过程，四轮实测用于计算补偿。最终命令应反映混合器归一化、速度限幅及目标斜坡，不能只比较原始拨杆指令与瞬时转速；命令偏差只能作为辅助证据，避免把超调和制动过程直接判成悬空

### 识别与保护状态

建议在模块中集中管理以下阶段，名称与接口待实施设计时确认：

1. 待确认：开始运行或数据恢复后，累计有效、同步的观测，不凭一个小残差样本确认接地
2. 运动一致：多周期残差处于允许误差内，正常小陀螺或跟随可以保持闭环；该状态仅证明观测一致
3. 异常可疑：残差持续超出误差范围，结合方向、角加速度和负载变化交叉检查，并先限制 yaw 推动权限
4. 受限保护：异常持续确认后撤销姿态追赶、捕获当前姿态；使用受限电流，底盘反馈不可信时禁止按轮速补偿值主动反向制动
5. 观测不可用：任一必需反馈缺失、过期、时间偏差过大或安装姿态超出模型范围时，不给予无限旋转豁免；进入受限输出或按已有故障路径停机

静态误差阈值、加减速附加容差、观测持续时间及恢复迟滞均需从接地旋转、启停、打滑与悬空录波中确定，不直接复用旧残差的 0.2/0.4/1 rad/s 阈值。时间对齐先于滤波，接收任务的发布时间不能替代电机源采样时间

异常解除后须经历持续一致窗口并渐进恢复；静止时残差为零不证明已经接地，只能支持继续受限监护。旋转模式切换不自动解除已确认的异常，正常主动旋转由实测补偿消除误触发

### 本轮计算核对

只读提取实际 `Mixer_Apply()` 的 OMNICROSS 四条表达式，使用固定随机种子 20261028 生成 10000 组平移与旋转组合，保留实际归一化和 100 rpm 尺度后检查平均轮速旋转项。全部通过，最大误差为 `1.4210854715202004e-14 rpm`；同时检查四轮冗余关系 `n1−n2+n3−n4=0`，该关系只能辅助发现部分轮速不一致，不能证明不打滑

取示意系数 `K_wz=0.05 rad/s 每 rpm` 检查七组代数样例：正反正常旋转、轮子空转、底座反作用旋转、部分打滑、静止、悬空但两路恰好一致。前两种正常旋转残差为零，三个不一致样例残差分别为 2、2、1.2 rad/s；最后一组同样得到零残差，明确保留不可区分工况

## 旧版简化备选：按遥控档位暂停低速判据

下列行为及接口为前一版备选，不能与首选方案混用；首选方案不按进入旋转模式自动解除异常保护

按有效遥控快照识别旋转意图，限制低速残差悬空保护的适用范围，不再仅凭残差区分主动旋转与悬空

| 模式意图 | 来源 | 低速残差保护 | 备注 |
| --- | --- | --- | --- |
| NONE | 左拨杆上位或中位 | 沿用现有检测、制动和自动恢复 | NONE 表示没有主动旋转意图，不表示实测停稳 |
| SPIN | 左拨杆下位且遥控有效 | 暂停低速异常累计、复发判断和低速撤驱包络 | 允许正常旋转产生的残差 |
| FOLLOW | 后续底盘跟随命令 | 预留与 SPIN 相同的旋转意图入口 | 本轮不映射拨杆，不实现跟随闭环 |
| UNKNOWN | 非法模式、无快照、离线、超时或时间回退 | 不给予旋转豁免 | 遥控无效仍按原流程两轴待机 |

旋转模式保留配置电流上限、目标速度上限、机械行程否决、反馈时效、非有限值检查和真实故障停机。现有 8/12/16 rad/s 的高残差电流包络也保留，本方案只限制低速悬空判据；高残差包络与实际小陀螺速度范围的兼容性须单独验证

遥控模式只能说明运动意图，不能证明底盘接地。SPIN 或未来 FOLLOW 下若发生真实悬空，低速残差保护同样受到上述限制；本方案不具备旋转模式中的独立悬空识别能力

## 接口与消息流建议

本方案使用枚举和函数参数，不新增或扩展结构体。以下名称为建议，尚未定稿

- 在 `User/module/gimbal.h` 定义 `Gimbal_ChassisMotion_t`，包含 NONE、SPIN、FOLLOW、UNKNOWN
- 在 `User/module/cmd.h/.c` 提供纯解析接口 `Cmd_ParseChassisMotion(rc, rc_valid, now_us)`，统一拨杆映射与 100 ms 帧龄校验，不访问队列或跨任务全局变量
- 增加 `Gimbal_ControlWithChassisMotion(gimbal, command, chassis_motion, period_s)`，将本周期模式沿参数传入 governor；原 `Gimbal_Control()` 保留并以 NONE 调用新入口，兼容现有调用方
- `User/task/motor_gimbal.c` 使用本任务已有 DR16 缓存，同时生成云台命令和底盘旋转意图；先读取快照，再采时间，两种解析共用同一时间值
- governor 在原状态机内集中处理模式变化，禁止任务层直接修改保护状态、PID 积分或电流

数据流为：DR16 独立云台邮箱 → 云台任务缓存 → 命令层解析 → 云台模块 → governor 状态机 → 原电流输出链

不读取另一个任务的 `chassis_command`，不新增 ISR 共享数据、RTOS 对象或临界区。跟随入口未来必须由有效命令来源按周期显式传入，不能通过永久布尔开关放行

FOLLOW 在本方案中仅代表未来底盘主动跟随云台的旋转意图。实际跟随所需的 yaw 相对角、零点、旋转方向、控制器和输出限幅留待后续设计；不直接把 FOLLOW 送入当前仅接受 INDEPENDENT 的底盘控制器

## 模式切换与保护状态交接

1. 进入 SPIN 或未来 FOLLOW：清除低速残差累计、滤波和复发历史，解除由该残差判据引起的制动、保持和监护约束；保留真实 FAULT 与 OFFLINE 行为
2. 若切换前处于 BRAKING、HOLD 或 RESTORING，先捕获当前 yaw 并清零前馈，再走渐进恢复，避免追赶已撤销的旧目标；原本正常闭环的姿态目标保持连续
3. 旋转模式持续期间不重复初始化、不重复捕获姿态，不因每周期解析而重启恢复斜坡；保护状态与运动意图由 governor 集中管理
4. SPIN 与 FOLLOW 互切属于同类旋转意图，不重复撤目标或重启渐进恢复
5. 退出旋转模式：清除旋转期间的低速残差历史，从当前反馈重新累计非旋转异常；恢复现有 0.15 s 检测规则，不增加额外盲区延时，高残差包络持续有效
6. 遥控失联、RELAX、无效周期及真实故障仍优先执行现有安全路径；非法旋转枚举不得提供豁免
7. 模式切换不直接清空 PID 积分，沿用最终执行电流的限步长反算；渐进恢复保留切换前实际电流历史并服从当前配置限幅
