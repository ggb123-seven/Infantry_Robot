# 云台任务与模块分层整理

日期：2026-10-22，范围为用户同意的云台业务迁移与主机脚本整理

## 最终归属

| 文件 | 职责 |
| --- | --- |
| `User/task/motor_gimbal.c` | 83 行，仅缓存反馈、恢复时间戳、调用模块、发布最新值命令和保持 500 Hz 调度 |
| `User/module/gimbal.c/.h` | 既有速度控制与独立角度外环接口 |
| `User/module/gimbal_capture.c/.h` | 阶跃及正弦实验状态机、冻结计划、同步采样、投影、CAN 采用统计 |
| `User/task/can_task.c` | 消费电流邮箱、调用设备接口、向采集模块回报采用电流与提交时刻 |
| `tools/gm6020` | 3 个 Python 和 5 个 MATLAB 主机辨识脚本 |

模块使用既有 `MOTOR_RM_Feedback_t`，任务邮箱继续使用迁移前已有的 `GimbalYawCommand_t`，未设计新结构体
模块公开计算、发布完成和 CAN 记录三个入口，完整时间戳均由任务传入，不读取任务句柄或 RTOS 邮箱
CMake 和 Keil 均已注册新模块源码，Python 默认工作区仍由脚本路径向上两级确定

既有实验阈值、缓冲容量、分组算法、调试变量名称与正常速度控制行为保持一致
角度环没有新增任务或 CAN 调用，后续仍由调用方显式连接
