# yaw 滑模控制器上板标定与整定（2026-11-23）

## 背景与授权

- 用户反馈上一版参数下 yaw「一直震动、超调太厉害」
- 参考 [滑模控制实战：从原理推导到代码调参](https://blog.csdn.net/weixin_30260191/article/details/170894464) 的整定流程：先辨识 J，再按期望收敛时间定 C，按扰动上界定 ε，K 起步约 2C，边界层 φ 最后压抖振，一次只改一个量
- 用户授权修改 `User/module/gimbal.c` 的滑模默认值和 `User/module/config.c` 的 yaw 参数，并烧录验证

## J 辨识

方法：yaw 速度调试模式下做 0 → +3 rad/s → 0 → -3 rad/s → 0 阶跃，记录速度与输出电流，用相邻采样差分求角加速度，取 0.5 A 饱和段斜率。

结果：

- 饱和段角加速度约 **220 deg/s²**
- 对应 `J_eff ≈ 2.2e-3 A/(deg/s²)`，约为原假定值 `7.08e-4` 的 3 倍
- 折算转动惯量约 0.09 kg·m²，其中包含摩擦导致的偏大

## 追加整定：参考轨迹与前馈（同日第二轮）

用户反馈「响应慢、抗扰弱、转动有声响」，继续按流程定位并修正：

- **J 修正**：0.5 A 脉冲测得的 2.2e-3 被摩擦污染；改用 3 A 阶跃饱和段速度斜率（约 3000~4000 deg/s²）重算，J 取 **8e-4 A/(deg/s²)**，折算惯量约 0.034 kg·m²
- **参考轨迹刹车约束**：原参考发生器按 `v=增益×误差` 加速，600 deg/s 附近刹车距离不足，参考自身会过冲 26%；改为只对误差修正项施加 `v ≤ √(2a·剩余角度)`，保留前馈速度，避免跟踪时把参考速度压成零
- **增益提升**：C=25、K=25、ε=150、φ=8，等效位置增益约 **1.1 A/deg**（此前 0.16 A/deg），3 A 限流
- **前馈加速度低通**：参考加速度 2500 deg/s² 乘 J 后约 2 A 的力矩前馈会在每次加减速时产生电流尖峰（实测小步进电流跳变 2~3 A），加 10 ms 一阶低通后削去尖峰
- **yaw 限流**：0.5 A → **3 A**，满杆 600 deg/s

| 项目 | 结果 |
| --- | --- |
| 60° 阶跃 | 上升 0.24 s，超调 **0%**，稳定 0.24 s，电流峰值 3 A（饱和约 2%） |

### 遥控通道现象

调试期间读取 `dr16_task.c::dr16_state`：`header.online=1`，但四个摇杆通道全为 0，`gimbal_command.yaw.rate_rad_s` 与 `pitch.rate_rad_s` 长期为 0，两轴角度在 90 秒内几乎不动。说明接收机在发中位/失控帧，需要确认遥控器是否开机、对频和接收机供电后再测遥控手感。

### 摩擦前馈与电流上限复测

- 用户试过把 yaw 限流临时提高到 10 A，确认力气足够但决定改回，最终仍取 3 A
- 增加 yaw 摩擦前馈：按参考速度方向补偿 0.2648 A，经 5 deg/s 的 tanh 平滑，零速时自动归零
- 摩擦前馈用于抵消低速起转和换向时的粘滞，减少切换项硬顶摩擦产生的声响和静差
- 烧录 `2a5e3eb3…` 后默认值读回：yaw 3 A、C=25、K=25、ε=150、φ=8、J=8e-4

## 验证边界与遗留

- 仅台架测试，遥控器离线，未做 RC 映射实测
- 静止仍有约 0.4° 稳态偏差，来自摩擦且滑模无积分项；可参考父工作树 yaw 摩擦前馈（约 0.2648 A）继续改善
- yaw 限流取 1.6 A 额定值；参考工作树用 10 A，竞赛需求确认后再评估
- 采样率只有 20~35 Hz，更高频的电流抖动需要更高采样率复核
