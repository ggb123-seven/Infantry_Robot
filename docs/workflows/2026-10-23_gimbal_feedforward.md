# 云台正弦跟随与目标角速度前馈

日期：2026-10-23

## 接口与控制链

按用户最初的正弦角度与余弦速度方案接入前馈，源码修改为 `User/module/gimbal.c`、`gimbal.h` 和 `User/task/motor_gimbal.c`
没有新增或修改公开结构体字段，没有修改 PID 公共组件、底层设备、CubeMX 配置或硬件资源

```c
Gimbal_Update(period_s, yaw_rate_feedback_rad_s, yaw_rate_feedback_valid, yaw_rate_feedforward_rad_s);
```

- 新增最后一个输入为目标角速度前馈，单位 `rad/s`，零表示关闭，正方向与目标角度增大方向一致
- `Gimbal_YawRunAt()` 同样增加最后一个前馈输入，所有工程调用点已更新
- 原有外部实际角速度输入仍只用于角度环反馈微分，速度内环继续使用编码器速度
- 前馈先按速度上限限幅，再与角度 PID 修正量相加，合成速度统一限幅后写入 `gimbal_yaw_speed.target_rad_s`
- 合成速度饱和且角度误差继续推向饱和方向时，撤销该周期角度环积分更新；反向误差允许积分退出饱和
- 禁用、未标定、反馈无效、非法增益、周期或前馈等条件仍阻断两环，前馈无法绕过原有保护
- `NaN` 或 `Inf` 前馈使本周期停机；接口前馈由同一调用方每周期提供，当前任务默认传入零

## 正弦测试

模块内部提供可关闭的实验轨迹，初始化时强制关闭：

```text
目标角度 = 180° + 30° × sin(6t)
目标角速度前馈 = π × cos(6t) rad/s
```

中心、振幅和相位角速度集中定义在 `gimbal.c` 顶部，目标始终在 150°～210° 内
同一相位同时生成角度和速度，首次启动相位为零，后续按当前实际周期推进并按 2π 回绕

| 变量 | 用途 |
| --- | --- |
| `gimbal_yaw_sine_test_enabled` | `true` 启用正弦轨迹，默认 `false` |
| `gimbal_yaw_sine_feedforward_enabled` | `false` 为无前馈基线，`true` 叠加余弦前馈，默认 `true` |
| `gimbal_yaw_feedforward_rad_s` | 只读本周期采用的前馈，单位 `rad/s`，总速度合成限幅前的值，停机时为零 |

- 测试启用时覆盖 `gimbal_yaw_angle.target_deg` 和接口前馈输入
- 切换前馈开关保持相位连续，便于同一条运动轨迹的前后对比
- 关闭测试后保持最后一次角度目标，并恢复采用接口前馈输入；当前任务接口传零，因此回到定点保持
- 停用控制、反馈异常或周期异常时轨迹回到待机，相位归零；控制恢复后从 180° 重新开始
- 反馈连续性丢失仍撤销机械零点及使能，需要重新标定并人工使能
- 非法测试枚举状态主动关闭测试与控制，默认输出为零
- 未增加 ISR 共享对象或临界区，所有状态由同一云台任务处理，`volatile` 只用于调试可见性

## 上板对比步骤

1. 载入本轮固件及对应 ELF，测试开关先保持关闭
2. 停用串级控制并确认零电流，按原有流程标定机械零点
3. 保留已整定的速度环与角度环参数，设 `target_deg=180` 后人工使能，等待实际位置接近 180°
4. 设 `gimbal_yaw_sine_feedforward_enabled=false`，再设 `gimbal_yaw_sine_test_enabled=true`，记录无前馈基线
5. 记录若干完整周期后，仅将前馈开关改为 `true`，继续记录同样长度
6. 比较目标角度、实际角度、角度误差和速度反馈，确认前馈开启时观测值符合余弦波
7. 结束时先停用串级，再关闭正弦测试并确认零电流

角度环增益默认仍为零，需要使用实际已整定值才能纠正角度误差
开启前馈时速度目标会立即加入当前余弦值；这次没有加入平滑启动包络
150°～210° 只是软件测试目标范围，真实机构是否可达必须结合机械行程核对
调试器若需暂停 MCU 才能修改 bool，先停用控制；暂停超过 90 ms 后反馈连续性保护会要求重新标定
当前未烧录或驱动电机，没有实测跟踪误差、相位滞后或闭环精度结果
