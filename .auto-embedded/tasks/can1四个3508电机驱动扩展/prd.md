# CAN1四个3508电机驱动扩展

## 需求 / 验收标准
- [x] CAN1 上注册 4 台 M3508，反馈 ID 为 `0x201~0x204`。
- [x] 4 台电机分别更新反馈并运行独立速度环，可分别设置目标转速。
- [x] 每周期只发送一次 `0x200` 组控制帧，4 个电流指令位于正确槽位。
- [x] 任一电机离线时该电机速度环禁用并下发零电流，不影响其他在线电机。
- [x] 关闭全局调试使能后，4 台电机持续下发零电流，连续 5 个成功周期后置停机就绪。
- [x] 当前调试固件上电默认开启速度环；暂停 Ozone 前需关闭全局调试使能并等待零电流停机就绪。
- [x] CMake Debug 构建成功，分层门禁通过。

## 约束
- 源码修改限定在 `User/task`，不修改 BSP、Device、CubeMX 生成代码和 `.ioc`。
- 保持 `task -> device/component -> bsp -> HAL` 依赖方向。
- 使用 Allman 花括号风格、120 列行宽和简体中文 UTF-8 注释。
- 不假定实车安装方向，4 台先均设为 `reverse = false`。
