# 为 C 板开启 USB CDC 虚拟串口用于 PID 变量实时调试

## 需求 / 验收标准
- C 板通过板载 USB 接口连接 Windows 后，能够稳定枚举为 CDC 虚拟串口，设备管理器中无反复掉线或重连。
- 以可配置的 100 Hz 默认频率发送目标值、反馈值、误差和控制输出，默认采用 VOFA+ JustFloat 帧格式。
- USB 未连接、主机未打开串口或发送端忙时，底盘控制任务不得阻塞；允许丢弃当前调试帧，并累计可观测的丢帧计数。
- 拔插 USB 后控制任务继续运行，重新连接后遥测能够自动恢复。
- CMake 构建无错误，烧录后完成 USB 枚举、连续数据接收和控制周期不受干扰的实机验证。

## 约束
- CubeMX 变更必须取得用户明确授权，由 CubeMX 生成 USB_OTG_FS 与 USB_DEVICE/CDC 代码。
- 应用侧新增源码默认只放在 `User/task`，不直接修改生成代码实现调试业务逻辑。
- 500 Hz 底盘控制任务只更新快照；低优先级调试任务负责组帧和发送，禁止在控制任务或中断中调用阻塞式 `printf`。
- USB 发送缓冲区在传输完成前必须保持有效，使用双缓冲避免覆盖正在发送的数据。
- 当前工程尚未实现 PID，首轮可用现有电机反馈验证链路；接入 PID 后再映射目标值、反馈值、误差和输出值。
