# 给单个 M3508 电机增加速度环缓启动与调试反馈接口

## 需求 / 验收标准
- 在 `User/task` 新增独立的单个 M3508 电机速度 PID 控制模块，复用现有 `User/component/pid.c` 中的 PID 库函数；该模块不实现底盘运动学、车体速度闭环或多电机同步控制。
- 仅实现速度闭环：速度 PID 输出为 C620/M3508 电流指令，不新增或声称实现软件电流环。
- 增加目标速度缓启动，目标变化时按配置的斜率逐周期逼近，避免电流指令突变。
- 预留宏定义形式的目标速度接口；目标速度、限幅后目标速度、缓启动目标速度和真实速度统一使用减速箱输出轴 `rpm`。
- 对目标速度设置正负对称限幅；对速度 PID 输出的电流指令设置独立正负对称限幅。
- 在速度控制模块中定义便于调试器观察的反馈结构体，关键字段使用简体中文集中说明并标明单位。
- `motor_chassis.c/.h` 作为主要运行文件，只保留单个 M3508 电机任务入口、任务循环、RM 设备驱动编排和速度控制模块 API 调用，不实现速度 PID 算法。
- `motor_speed_control.c/.h` 只保存并实现速度环控制部分，不拥有任务入口，不直接调用 RM 设备驱动。
- 电机离线、初始化失败或控制计算异常时下发零电流，并清除 PID 与缓启动状态，避免恢复时突跳。
- CMake 与 Keil 工程均纳入新增速度控制源文件，且现有任务入口保持可链接。
- 通过 CMake Debug 编译、auto-embedded 机械门禁和代码人工检查；硬件方向与动态响应需在上板低速测试中确认。

## 约束
- 源码修改严格限制在 `User/task`；构建配置按本任务需要可修改。
- 不修改 `.ioc`、BSP、设备驱动、CubeMX 生成代码或第三方组件。
- 新增或修改的代码注释使用简体中文和 UTF-8 编码，函数注释使用 Doxygen 风格。
- 控制任务频率沿用现有 `500 Hz`，速度控制周期按 `2 ms` 使用。
- 上电默认目标速度为 `0 rpm`，非零速度由用户修改预留宏后启用。
