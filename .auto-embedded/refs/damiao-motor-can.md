# 达妙电机 CAN 协议与选型参考

> 当前重点覆盖 DM-J4310-2EC V1.1。原始手册和 2026 选型资料保存在 `docs/datasheets/`。
> 达妙参数和协议随固件、产品版本、24 V/48 V 型号变化明显，使用前必须核对铭牌和调试助手配置。

## 项目约束

- 本项目主控为 RoboMaster C 板（STM32F407IGH6），板载外设是经典 bxCAN，不支持原生 CAN FD。
- DM-J4310-2EC V1.1 的 2026 选型资料标注支持 CAN、CAN FD；在本项目中默认只使用经典 CAN。
- 本地 J4310 使用说明书明确的经典 CAN 固定比特率为 `1 Mbps`，使用标准帧。
- CAN 引脚、收发器、电源和终端电阻必须以 C 板原理图及项目配置为准。

### 版本处理原则

- 旧手册与新选型资料的额定相电流、峰值相电流、相阻和通信能力不一致。
- 驱动限幅、保护阈值和模型参数不得只按文件名或网络示例硬编码。
- 上电前通过铭牌和达妙调试助手确认：产品版本、供电版本、固件版本、控制模式、CANID、MasterID、`P_MAX`、`V_MAX`、`T_MAX` 和保护阈值。
- 2026 资料只表明设备具备 CAN FD 能力，本地资料没有提供 CAN FD 帧定义；不得据此自行推断 CAN FD 协议。

## 经典 CAN 反馈帧

- 帧类型：标准数据帧，比特率 1 Mbps。
- 反馈帧 CAN ID 由 `MasterID` 决定，默认 `0`。

| 字节 | 位域 | 含义 |
|---|---|---|
| D0 | 高 4 位 ERR，低位 ID | 位域表写作 `(ERR << 4) \| ID`；正文又称 ID 取 CAN_ID 低 8 位，两个描述存在歧义 |
| D1–D2 | `POS[15:0]` | 位置，16 位线性映射值 |
| D3 | `VEL[11:4]` | 速度高 8 位 |
| D4 | `VEL[3:0] \| T[11:8]` | 速度低 4 位、扭矩高 4 位 |
| D5 | `T[7:0]` | 扭矩低 8 位 |
| D6 | — | MOS 平均温度，℃ |
| D7 | — | 电机线圈/转子平均温度，℃ |

故障码：

| ERR | 含义 |
|---:|---|
| `0x8` | 超压 |
| `0x9` | 欠压 |
| `0xA` | 过电流 |
| `0xB` | MOS 过温 |
| `0xC` | 电机线圈过温 |
| `0xD` | 通讯丢失 |
| `0xE` | 过载 |

位置使用 16 位映射，速度和扭矩使用 12 位映射。映射上下限不是协议常量，必须使用调试助手中的当前配置：

```text
raw = round((value - min) * ((1 << bits) - 1) / (max - min))
value = raw * (max - min) / ((1 << bits) - 1) + min

position_raw = (D1 << 8) | D2
velocity_raw = (D3 << 4) | (D4 >> 4)
torque_raw   = ((D4 & 0x0F) << 8) | D5
```

D0 解码应先按当前固件和调试助手版本做实机抓包验证。常见实现使用 `error = D0 >> 4`、`id = D0 & 0x0F`，但在未验证前不要把该掩码当作跨版本固定规则。

来源：`docs/datasheets/Damiao_DM-J4310-2EC_User_Manual_V1.0.pdf`，PDF 第 6–7 页。

## MIT 模式

- 控制 CAN ID：设备配置的 `CANID`。
- DLC=8。
- `p_des` 16 位；`v_des`、`Kp`、`Kd`、`t_ff` 各 12 位。

| 字节 | 内容 |
|---|---|
| D0 | `p_des[15:8]` |
| D1 | `p_des[7:0]` |
| D2 | `v_des[11:4]` |
| D3 | `v_des[3:0] \| Kp[11:8]` |
| D4 | `Kp[7:0]` |
| D5 | `Kd[11:4]` |
| D6 | `Kd[3:0] \| t_ff[11:8]` |
| D7 | `t_ff[7:0]` |

量程和模式：

- `p_des`、`v_des`、`t_ff` 使用调试助手配置的 `P_MAX`、`V_MAX`、`T_MAX`。
- `Kp` 范围 `[0, 500]`，`Kd` 范围 `[0, 5]`。
- `Kp=0`、`Kd>0`，主要给定 `v_des`：可形成速度控制。
- `Kp=0`、`Kd=0`，主要给定 `t_ff`：可形成扭矩输出。
- 位置控制时 `Kd` 不能为 0，否则可能震荡甚至失控。

来源：`docs/datasheets/Damiao_DM-J4310-2EC_User_Manual_V1.0.pdf`，PDF 第 5、7 页。

## 位置速度模式

- 控制 CAN ID：`0x100 + CANID`。
- D0–D3：`p_des`，IEEE 754 `float32`，低字节在前，单位 rad。
- D4–D7：`v_des`，IEEE 754 `float32`，低字节在前，单位 rad/s。
- `v_des` 表示梯形加减速过程中匀速段的最高速度。
- 阻尼因子必须为非 0 正数。

来源：`docs/datasheets/Damiao_DM-J4310-2EC_User_Manual_V1.0.pdf`，PDF 第 5–7 页。

## 速度模式

- 控制 CAN ID：`0x200 + CANID`。
- D0–D3：`v_des`，IEEE 754 `float32`，低字节在前，单位 rad/s。
- 手册表格只定义 4 个有效数据字节；发送 DLC 8 时应把 D4–D7 清零，不能保留未初始化数据。
- 阻尼因子建议 2.0–10.0，推荐 4.0；过小容易震荡和过冲，过大会增加上升时间。

来源：`docs/datasheets/Damiao_DM-J4310-2EC_User_Manual_V1.0.pdf`，PDF 第 6、8 页。

## 保护建议

2023 使用说明书给出的建议值：

- 电机温度保护不超过 100 ℃。
- 过压保护不超过 32 V。
- 过流保护不超过 9.8 A。
- 供电电压不低于 15 V。
- 配置通讯丢失保护，在设定周期内未收到 CAN 指令时退出使能。

这些值不是所有版本的统一默认值；48 V 型号必须按对应资料和调试助手重新确认。

来源：`docs/datasheets/Damiao_DM-J4310-2EC_User_Manual_V1.0.pdf`，PDF 第 9 页。

## 与 RoboMaster 电机共总线的冲突风险

以下是由两套原厂协议 ID 映射直接得到的工程推论：

- RoboMaster C620/C610 使用 `0x200` 作为 ID 1–4 的组控制帧。
- 达妙速度模式使用 `0x200 + CANID`；当 `CANID=0` 时直接占用 `0x200`。
- 达妙速度模式的 `0x201..0x208` 会与 C620/C610 的反馈 ID 区间重叠。
- 达妙 MIT 模式直接使用设备 CANID，也可能与现有标准帧 ID 重叠。
- 达妙反馈默认 MasterID 为 0；修改 MasterID 时也必须避开其他设备的控制和反馈 ID。

因此：

1. 混用前先建立完整的“发送 ID/接收 ID/设备/方向”分配表。
2. 无法消除冲突时，使用 C 板的另一条 CAN 总线进行物理隔离。
3. 过滤器只能减少 MCU 接收负担，不能解决线上相同 ID 的语义冲突。
4. 联调时先禁用执行输出，仅监听实际帧，再逐台使能。

## 调试清单

1. 确认经典 CAN、标准帧、1 Mbps。
2. 从调试助手读取并记录 CANID、MasterID、模式和全部映射上限。
3. 确认 24 V/48 V 版本，按对应建议供电范围设置电源限流。
4. 首帧目标设为当前位置、零速度、零前馈，`Kp/Kd` 从低值开始。
5. 浮点控制帧使用小端序；MIT 模式按位打包。
6. 反馈帧使用设备当前量程解码，不能复制其他项目的 `P_MAX/V_MAX/T_MAX`。
7. 实现通讯超时、温度、过压、欠压、过流和急停处理。
8. 先空载或机构架空测试，再连接实际负载。
